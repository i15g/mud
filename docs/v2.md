Options:
-h, --help Show this help
-d, --dry-run Sanitize filename and show what would be renamed
-t, --text Sanitize text and output result (don't rename file)
-q, --quiet Rename file and output only the new path
-r, --recursive Rename all files/dirs under path (bottom-up)

## Allowed prefixes

- periods and underscores

## Replacements

URL-decode: `%20` → space, `%28/%29` → parens, etc

Special cases:

| Before       | after  |
| ------------ | ------ |
| @            | -at-   |
| &            | -and-  |
| A-acute, etc | a, etc |
| A/O/U umlaut | a/o/u  |

## Ignore Patterns

These may be overridden with the -f/--force flag.

- dotfiles
- UPPERCASE.ext (e.g. README.md)
- File extensions where mud would break conventions:
  - java, scala
  - python?
  - etc
- Known filenames:
  - Thumbs.db
  - desktop.ini
  - ehthumbs.db
