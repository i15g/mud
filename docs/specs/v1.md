# mud v1

## Overview

mud is a Go CLI that renames files to URL-friendly format. Single positional arg,
custom flag parser, no external dependencies.

## Sanitize Pipeline

`Sanitize()` processes a name through these steps in order:

1. **Preserve leading dots** — stripped temporarily, restored at end
2. **Extract last extension** — single extension via `strings.LastIndex`; no multi-extension
   support (`foo.tar.gz` → stem `foo.tar`, ext `.gz`)
3. **Strip leading underscores from stem** — preserved, restored at end
4. **Lowercase stem**
5. **Replace separators with hyphens**: space, `\n`, `_`, `,`, `+`
6. **Collapse 3+ hyphens → 2**
7. **Remove chars not in `[a-z0-9.-]`** — interior periods in stem are preserved
8. **Trim leading/trailing hyphens**
9. **Lowercase extension**

## CLI

### Flags

| Flag              | Notes                         |
| ----------------- | ----------------------------- |
| `-h, --help`      |                               |
| `-d, --dry-run`   |                               |
| `-t, --text`      | sanitize and print, no rename |
| `-q, --quiet`     | print new path only           |
| `-r, --recursive` |                               |

Custom hand-rolled parser — supports combined short flags (`-rd`), stops at first
non-flag arg. Only the first positional arg is used; extras are silently ignored.

### Output Modes

| Mode           | Output                                 |
| -------------- | -------------------------------------- |
| default        | `old -> new`                           |
| `-q/--quiet`   | new path only                          |
| `-d/--dry-run` | `old --> new\n(dry run)\n` (two lines) |

### No-clobber

If the target already exists and is a different file, rename is silently skipped.
Case-only renames (e.g. `FOO` → `foo`) are allowed via `os.SameFile`.

### Recursive Mode

Bottom-up traversal via `filepath.WalkDir`, sorted in reverse so deepest paths
rename first. Skips `.git`. Errors abort remaining files.

## Limitations (addressed in v2)

- Single extension only (`foo.tar.gz` loses `.tar`)
- No ignore patterns — renames dotfiles, `README.md`, source files, etc.
- Default output is `old -> new`; v2 flips this to new-path-only for scripting
- `-q` prints new path; v2 makes `-q` silent and new-path-only the default
- No stdin support — requires `-t` flag for text mode
- Single positional arg only
- No interactive mode
- Dry-run prints two lines; v2 uses one line with `->`
- Clobber is a silent skip; v2 errors instead
