# mud

Rename files to URL slug style format.

## Install

```sh
go install github.com/i15g/mud@latest
```

Or in a Brewfile:

```
go "github.com/i15g/mud"
```

## Usage

```
mud [options] <filename|text>
```

See top of [main.go](main.go)
